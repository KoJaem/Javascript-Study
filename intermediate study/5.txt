toString() 메소드
10진수 -> 2진수/16진수

예시 코드
        let num = 10;
        console.log(num.toString()); // "10"
        console.log(num.toString(2)); // "1010"

        let num2 = 255;
        console.log(num2.toString(16)); // "ff"

Math 객체
Math.PI; // 3.141592653589793
Math.ceil() : 올림
Math.floor() : 내림
Math.round() : 반올림


예제 코드
        let num1 = 5.1;
        let num2 = 5.7;
        console.log(Math.PI);
        console.log(Math.ceil(num1));
        console.log(Math.ceil(num2));
        console.log(Math.floor(num1));
        console.log(Math.floor(num2));
        console.log(Math.round(num1));
        console.log(Math.round(num2));


출력결과 : 3.141592653589793
	 6
	 6

	 6

만약에 소수점 자릿수를 셋째자리에서 반올림하여 둘째자리까지 표현하고 싶은 상황이 오면
1. 100을 곱한다
2. 반올림을 한다
3. 100으로 나눈다 를 하면 된다.

예제 코드
// userRate를 셋째자리에서 반올림하여 둘째자리까지 표현하는 코드
        let userRate = 30.1234;

        console.log((userRate*100)); // 3012.34

        console.log(Math.round(userRate*100)); // 3012

        console.log(Math.round(userRate*100)/100); // 30.12


출력결과 : 3012.34
	 3012
	 30.12

더 간단한 방법은 toFixed() 메소드를 사용하면 된다

Number(userRate.toFixed(2)); // 3012

isNaN() : NaN인지 아닌지 판단해줌 (NaN이란 Not a Number를 뜻함.
			        즉, 숫자값이지만 (컴퓨터로는) 표현할 수 없는 숫자값)

        let x = Number('x'); // NaN

        console.log(isNaN(x)); // true
        console.log(isNaN(3)); // false

출력결과 : true
	 false




parseInt() : 문자를 숫자로 바꿔줌 (Number와 다른점은 문자가 섞여있으면 읽을 수 있는곳까지 숫자를 반환함.)
예제 코드
        let margin = "10px";
        console.log(parseInt(margin)); // 10
        console.log(Number(margin)); // NaN
        let redColor = "f3";
        console.log(parseInt(redColor)); // parseInt도 처음부분에 숫자가 안나오면 NaN 반환
        console.log(parseInt(redColor)); // NaN
출력결과 : 10
	 NaN
	 NaN
	 NaN



parseInt() 활용 (매개변수 두개 사용) / parseInt("바꿀 문자", 몇진수로 할지);
예제코드
        let redColor = "f3";
        parseInt(redColor); // NaN
        console.log(parseInt(redColor,16)); // 243
        console.log(parseInt("11",2)); // 3

출력결과 : 243
	 3




parseFloat() : parseInt와 똑같이 동작하지만, 부동소수점을 반환함.

        let padding = "18.5%";
        console.log(parseInt(padding)); // 18 , parseInt는 소수점은 무시하고 정수만 반환함.
        console.log(parseFloat(padding)); // 18.5

출력결과 : 18
	 18.5
