주의할점
1. 자바스크립트에서 문자는 항상 따옴표로 감싸줘야함. ' , ' 또는 " , " 또는 ` , ` 도 있음( ` , ` 이건 2장에서 설명).
2. class = "수업"; 은 에러임. 이유는 class 가 이미 자바스크립트에서 사용하는 단어인 예약어 이기 때문

변수 선언에 앞서
let 키워드를 사용하여 이미 선언되어있는 변수인지 확인할 수 있다.

ex) let name = "JaeMin";

// ~~~~~ 1000 line 뒤

let name = "KoJaeMin"; // 에러

즉, 변경을 하는게 아닌 최초로 사용하는 변수 선언시에는 let 을 사용하는것이 좋다.



const 키워드
절대로 바뀌지 않는 상수. 즉, 수정이 불가능한 변수를 선언할 때 사용.
관례적으로 const변수는 대문자로 선언함.
(안바뀌는 변수를 예시로 들자면 파이, 생일, 주민등록번호 등)




1. 변수는 문자, 숫자, $, _ 만 사용
2. 변수의 첫글자는 숫자가 될수없음
3. 변수이름을 예약어로 사용할 수 없음
4. 관례적으로 상수는 대문자로 사용함
5. 변수명은 읽기 쉽고 이해할 수 있는 이름으로 선언하는게 좋음
