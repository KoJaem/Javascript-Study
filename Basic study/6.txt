프롬프트로 입력받은 값은 무조건 문자형이다.

          const mathScore = prompt("수학 몇점?");
          const engScore = prompt("영어 몇점?");
          const result = (mathScore + engScore)/2;

          console.log("평균값은 "+ result + "입니다.");


이 코드에서
수학 100점, 영어 100점 이라고 했을때
평균값이 100점으로 나와야 하지만,

prompt에서 받은값은 무조건 문자형 이므로
"100" + "100" = 100100 이고,
나누기 2를 하여 50050 이 된다.
(숫자가 아니더라도 나누기같은 표현식은 숫자형으로 자동 형변환이 돼서 사용됨)


명시적 형변환

String() unknown의 타입을 문자형으로 바꿔줌.

          console.log(
            typeof(String(3)) ,
            typeof(String(true)),
            typeof(String(false)),
            typeof(String(null)),
            typeof(String(undefined)));

출력값 : string string string string string




Number() unknown의 타입을 숫자형으로 바꿔줌.

          console.log(
            typeof(Number(3)) ,
            typeof(Number(true)),
            typeof(Number(false));
	console.log(Number(true));
	console.log(Number(false));
출력값 :
number number number
1 // true는 1
0 // false는 0

주의 : Number("문자~~"); 는 NaN으로 출력됨.



Bollean() boolean 타입으로 바꿔줌.
숫자0, 빈 문자열"", null, undefined, NaN 같은 경우에만 false,
나머지는 true로 반환함.

          console.log(
            Boolean(0),
            Boolean(""),
            Boolean(null),
            Boolean(undefined),
            Boolean(NaN));
